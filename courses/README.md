# 数学课程源笔记

从 [数学学习导航](数学/00-数学学习导航.md) 开始。这里保存可编辑的 Markdown 教材，博客副本由现有笔记发布器生成。

包含微积分 11 篇、线性代数 11 篇、泛函分析 19 篇，另有总导航 1 篇。各正文从带数字的生活问题出发，展开计算与推理，最后整理定义、工具与练习。配图按章节维护，积分一章配有十幅逐步图解。图示为课程目录下的本地 SVG，不依赖远程图床。

各章练习先集中列出题目，后面单列参考答案与解题过程，方便先独立作答再核对。

在仓库根目录执行：

```sh
pnpm notes:plan --vault courses
pnpm notes:publish --vault courses --write
pnpm build
```

以上生成本地公开副本和站点，不执行 Git 提交、推送或线上部署。后续修改此处源笔记，再重新导出，不要直接修改 `src/content/posts` 中受发布清单管理的副本。命令显式指定 `--vault courses`，无需改动现有私有笔记库配置。

本目录有意收录可公开的课程内容，不存放私人笔记或原始视频素材。图示与文字按学习路线独立编写，外部官方课程只作伴读。
